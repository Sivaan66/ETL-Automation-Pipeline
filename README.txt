# Learning: Building an Automated Data Pipeline

This repository documents my learning journey while building an automated data pipeline using Python.

## Topics Explored

- Working with REST APIs
- Fetching data incrementally
- Handling missing values
- Data validation
- Idempotent processing
- Deduplication
- Metadata generation
- Automating dataset publishing with the Kaggle API
- Error handling and debugging

## Why I Built This

Instead of following isolated tutorials, I wanted to learn by building a complete workflow from data ingestion to automated publishing. This notebook contains experiments, notes, and code developed during that process.

## Technologies

- Python
- Pandas
- Requests
- Jupyter Notebook
- Kaggle API
